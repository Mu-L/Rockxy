# License Management

<Note>
The **License** settings tab is part of the official signed Rockxy
distribution. It is not included in builds made solely from the public AGPL
Community source repository.
</Note>

## How licensing fits into Rockxy

The official app is one installed binary with runtime capability states:

- without a paid entitlement, it runs in free **Community** mode;
- with an eligible entitlement, it unlocks **Pro** capabilities; and
- if an entitlement becomes invalid or does not cover the installed build, the
  app returns to Community mode or keeps only the rights the entitlement still
  provides.

The official binary is built from a separate downstream distribution and is
licensed under the [Rockxy Binary EULA](https://github.com/RockxyApp/Rockxy/blob/main/legal/BINARY-EULA-v1.0.md). The public
source repository remains separately available under AGPL-3.0-or-later. See
[Rockxy Licensing](https://github.com/RockxyApp/Rockxy/blob/main/LICENSING.md).

## Perpetual licenses and update coverage

When a Rockxy plan is sold as perpetual, the entitlement remains usable for
eligible app builds. Included updates end on the **Updates until** date shown in
the app:

- builds released on or before that date remain eligible;
- a newer build may require renewed update coverage; and
- installing a newer ineligible build does not turn the public source edition
  or Community mode into a paid product.

The checkout terms for a purchase control its exact device count, update
period, refund terms, and included capabilities.

## License states

The **Status** field can show states such as:

| Status | Meaning |
| --- | --- |
| **Community** | No Pro entitlement is active on this Mac. |
| **Pro (active)** | Pro is active and the installed build is covered. |
| **Pro (current version only)** | Update coverage ended, but this installed build remains covered. |
| **This Build Is Newer Than Your License** | The installed build is outside the covered updates window. |
| **Validation failed** | Rockxy could not verify the securely stored entitlement. |
| **Suspended** | The entitlement is not currently authorized for use. |
| **Deactivated** | Pro was removed from this Mac. |

## Activate, restore, validate, or deactivate

Open **Rockxy → Settings → License** in the official app. Depending on the
current state, Rockxy presents the relevant actions:

- **Enter License Key…** activates an eligible license on this Mac.
- **Restore on This Mac** reconnects to a securely stored license after access
  or local state needs recovery.
- **Retry Validation Now** repeats validation after a temporary failure.
- **Deactivate on this Mac** removes Pro from the Mac and releases the
  activation when supported by the plan.

To move a license, deactivate the old Mac first when possible, then activate
the new Mac using the purchase credentials associated with the license.

## Common failures

| Condition | Recommended action |
| --- | --- |
| Invalid key or purchase identity | Re-enter the exact purchase details. |
| Activation limit reached | Deactivate an old Mac or review the purchased device scope. |
| Build newer than coverage | Renew updates or install an eligible version. |
| Provider temporarily unreachable | Retry later without repeatedly changing the stored key. |
| Secure access denied | Allow the requested Keychain access and retry. |
| Suspended or disabled entitlement | Contact Rockxy support with non-sensitive purchase details. |

Never post a license key in an issue, discussion, screenshot, log, or support
message.
